# Linux Deploy Portfolio API

Projeto desenvolvido para demonstrar conhecimentos práticos em:

- Linux
- Docker
- Docker Compose
- FastAPI
- Deploy de aplicações
- Estruturação de APIs
- Ambientes containerizados

---

# Objetivo

Simular um cenário real de deploy profissional utilizando Linux e Docker para publicação de aplicações backend.

---

# Tecnologias utilizadas

- Python 3.12
- FastAPI
- Docker
- Docker Compose
- Linux Ubuntu
